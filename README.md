# 🖥️ 우테코 최종 미션 연습 - [자판기]

- 기능 요구 사항에 기재되지 않은, 스스로 판단한 부분은 **볼드체** 사용

## 📖 프로젝트 개요

- 자판기가 보유하고 있는 금액으로 동전을 무작위 생성
    - 투입 금액으로는 동전을 생성하지 않음
- 잔돈을 돌려줄 때 현재 보유한 최소 개수의 동전으로 돌려줌
- 지폐를 잔돈으로 반환하는 경우는 없다고 가정
- 상품명, 가격, 수량을 입력해 상품 추가 가능
    - 상품 가격은 100원부터 시작하며, 10원으로 나누어 떨어져야 함
- 사용자가 투입한 금액으로 상품 구매 가능
- 남은 금액이 상품의 최저 가격보다 적거나, 모든 상품이 소진된 경우 바로 잔돈 돌려줌
- 잔돈을 반환할 수 없는 경우 잔돈으로 반환할 수 있는 금액만 반환
    - 반환되지 않은 금액은 자판기에 남음
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고,
  "[ERROR]"로 시작하는 에러 메시지 출력 후 그 부분부터 다시 입력 받음

## ⌨️ 입출력 요구 사항

### 입력

- 자판기가 보유하고 있는 금액
    - 빈 문자열을 입력한 경우 예외 발생
    - 숫자를 제외한 문자를 입력한 경우 예외 발생
    - 숫자가 int 범위를 초과한 경우 예외 발생
- 상품명, 가격, 수량
    - 형식 예시: [콜라,1500,20];[사이다,1000,10]
    - 빈 문자열을 입력한 경우 예외 발생
    - 형식이 맞지 않는 경우 예외 발생
    - 상품 가격과 상품 수량이 int 범위를 초과한 경우 예외 발생
    - 상품명이 중복된 경우 예외 발생
    - 상품 가격이 100원 미만일 경우 예외 발생
    - 상품 가격이 10원으로 나누어 떨어지지 않는 경우 예외 발생
    - 상품 수량이 1개 미만일 경우 예외 발생
- 투입 금액 입력
    - 빈 문자열을 입력한 경우 예외 발생
    - 숫자를 제외한 문자를 입력한 경우 예외 발생
    - 숫자가 int 범위를 초과한 경우 예외 발생
- 구매할 상품명 입력
    - 존재하지 않는 상품명일 경우 예외 발생
    - 재고가 없는 상품명일 경우 예외 발생

### 출력

- 자판기가 보유한 동전

```
500원 - 0개
100원 - 4개
50원 - 1개
10원 - 0개
```

- 잔돈은 반환된 동전만 출력

```
100원 - 4개
50원 - 1개
```

- 에러 문구
    - [ERROR]로 시작

## 📜 프로그래밍 요구사항

### Coin 클래스

- Coin 클래스를 활용해 구현
- 필드(인스턴스 변수)인 amount의 접근 제어자 private 변경 불가능

```
public enum Coin {
    COIN_500(500),
    COIN_100(100),
    COIN_50(50),
    COIN_10(10);

    private final int amount;

    Coin(final int amount) {
        this.amount = amount;
    }

    // 추가 기능 구현
}
```

### Randoms, Console

- `camp.nextstep.edu.missionutils`에서 제공하는 `Randoms`, `Console` API를 활용
    - Random 값 추출은 `camp.nextstep.edu.missionutils.Randoms`의 `pickNumberInList()`를 활용
    - 사용자가 입력하는 값은 `camp.nextstep.edu.missionutils.Console`의 `readLine()`을 활용
